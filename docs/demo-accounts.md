# Demonstration accounts (local development only)

Created by `npm run db:seed`. The password for all of them is `SEED_DEMO_PASSWORD` in your `.env.local` (generated by `npm run setup`). These accounts and the customer organisations are demonstration data. **Never seed them into production.**

Accounts holding a privileged permission must set up an authenticator app (TOTP) at first sign-in.
